# Прототип M4v2

[Отчёт](reports/report_m4_v2_ru.md) содержит оба исследовательских раунда,
неудачные варианты, выбор T30, ограничения, статистику и проверку сценариев.
Исходный M4 не заменён. r6.2 не загружался: пользователь выбрал прототип на r4.2/r5.2.

Результаты находятся в `results/m4_v2_development/`. Файлы выбора и планов фиксируют
порядок разработки. Их не нужно удалять или редактировать для повторного запуска.
Код первого и второго раундов намеренно запрещает изменение зафиксированного плана;
для воспроизведения используйте **новый** каталог:

```powershell
python -m ueba.development.reproduce --output results/m4_v2_reproduction
python -m pytest -q
```

Нужны подготовленные результаты основных экспериментов r4.2/r5.2: parquet-файлы
`raw_scores` и `validation_predictions` для пяти seeds в `results/primary/` и
`results/r5_2/primary/`. Как получить их из исходных журналов — в README.md и
README_R5_2.md. Детекторы при разработке не переобучаются. Разработка читает только
calibration/validation; исходный test не используется для выбора и повторной оценки
нового метода. Данные, preprocessing, detector, официальные метки и исходные методы
соответствуют уже проведённой репликации.

При воспроизведении порядок такой: первый раунд; второй раунд; 9999 cluster-bootstrap
выборок; дополнительные временные контроли. Обе формулы и правила отбора заданы в
docs/protocol_m4_v2*.md. Код размещён в ueba/development/, отдельно от исходной
ueba/calibration/. Дополнительные TM2–TM4 введены после просмотра основного аудита,
не участвовали в выборе T30 и имеют отдельную исследовательскую семью Holm.

Пересобрать только отчёт/рисунки по сохранённым результатам:

```powershell
python -m ueba.development.report
python tools/verify_m4_v2.py
```

Отчёты и графики отражают исследовательские результаты на ранее изученных выпусках;
статистическая значимость здесь не доказывает независимую переносимость. Новый вариант
улучшил Recall относительно M3/M4 на r5.2, но не установил превосходство над всеми
персональными абляциями и не улучшил максимальный ролевой FPR на обоих выпусках.
