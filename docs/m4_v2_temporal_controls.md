# Дополнительная диагностика временного накопления

Эта проверка добавлена **после просмотра** основного аудита второго раунда.
Она не участвует в выборе прототипа T30 и не изменяет его формулу или пороги.
Цель — проверить, можно ли объяснить выигрыш простым усреднением исходных методов.

Для M2/M3/M4 применяется то же среднее за 7 календарных дней по пользователю,
включая текущий день, что для T30. Пороги задаются на той же первой половине
validation; оценка — на второй. Названия: TM2, TM3, TM4. Из этого сравнения новый
победитель не выбирается. Статистика условная, исследовательская; отдельная семья
Holm: T30 против трёх контролей, два выпуска, Recall@1% и max-role FPR, 12 тестов.
Её нельзя считать заранее заявленной подтверждающей проверкой.
